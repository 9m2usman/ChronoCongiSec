
# Shared Contracts Ownership

**Coordinator: M1**

Shared schemas, enums, and events affect multiple modules.

Responsibilities:
- M1 coordinates naming and API consistency.
- M2 reviews gateway and execution contracts.
- M3 reviews memory and provenance contracts.
- M4 reviews security and incident contracts.
- M6 reviews database-related contracts.
